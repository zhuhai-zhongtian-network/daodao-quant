# DeepSeek + 豆包：10分钟打造“国企标准”工作总结PPT 全流程

> 分类：市场复盘 ｜ 标签：上市公司、公文写作、工作总结

---

这是一个非常高效的 AI 协同工作流设计。为了让这套流程在实战中更顺滑、产出更符合“国企/商务”标准，我对提示词进行了结构化升级。


升级重点在于：增强角色沉浸感、细化 Markdown 格式约束（这对后续生成至关重要）以及强化视觉设计的指令颗粒度。


以下是为您优化的完整操作指南及标题建议：






### 🚀 优化后的操作指南

#### 第一步：深度萃取——利用 DeepSeek 生成高质量演讲稿

操作： 将你的年度工作数据、碎片化记录、项目清单等素材投喂给 DeepSeek。


📋 优化提示词（可直接复制）：




Role: 资深国企管理咨询顾问 / 首席文案专家
Task:
基于我提供的【原始素材】，撰写一份高质量的**年终总结演讲稿**。



Requirements:

 	- 
基调定位： 务实、大气、逻辑严密，体现“稳中求进、进中提质”的国企/大型企业管理风格。




 	- 
结构逻辑： 按照“核心成绩概览（数说202X） -&gt; 重点工作复盘（亮点与突破） -&gt; 问题与挑战（深度剖析） -&gt; 明年规划与举措（战略落地）”的逻辑展开。




 	- 
内容要求：




 	
量化优先： 尽可能用数据说话，对于模糊的描述尝试转化为增长率、完成率等指标。




 	- 
措辞升维： 使用专业、精炼的管理术语（如：降本增效、数字化转型、护城河、闭环管理等），避免过于口语化。




 	- 
篇幅： 演讲时长控制在 10 分钟左右（约 2500 字）。







Context (原始素材):
[在此处粘贴您的原始数据/记录]






#### 第二步：结构重塑——DeepSeek 一键转为 PPT 大纲

操作： 在同一个对话窗口中，要求 AI 将演讲稿转化为标准化的 PPT 结构代码。


📋 优化提示词（可直接复制）：




很好，请继续。



Task:
基于刚才生成的演讲稿，将其拆解为一份 12页 的 PPT 制作大纲。



Output Format:
请严格使用 Markdown 代码块格式输出，不要包含任何其他解释性文字，格式如下：




Markdown




# Slide [页码]: [精炼的标题，不超过10个字]
## 核心观点: [一句话总结本页核心思想]
- [关键点1]
- [关键点2]
- [关键点3]
*[视觉建议]: 建议使用柱状图/流程图/关键词云等*




Constraints:

 	- 
页数控制： 精准控制在 12 页（含封面和封底）。




 	- 
内容提炼： 每页要点控制在 3-5 个以内，确保 PPT 页面不拥挤，适合“白底”商务风格。









#### 第三步：精细校核（中间件环节）

操作： 将 DeepSeek 输出的 Markdown 代码复制到在线编辑器（如 https://markdown.lovejade.cn/ 或各类笔记软件）进行快速浏览。




 	- 
检查： 标题是否对齐？关键数据是否遗漏？逻辑链条是否通顺？








#### 第四步：AI 注入——豆包 自动化生成 PPT

操作： 打开豆包（或其 PPT 生成功能模块），输入以下指令。


📋 优化提示词（可直接复制）：




Role: 专业商务演示文稿设计师 (专注于国企/上市公司年报风格)
Task:
请基于以下 Markdown 大纲，为我生成一份完整的 PPT 文件。



Design Specs (设计规范):

 	- 
整体风格： 现代简约商务风（Modern Business），强调严谨、大气、呼吸感。




 	- 
配色方案（严格执行）：




 	
背景： 纯白 (#FFFFFF) —— 确保打印友好及视觉清爽。




 	- 
主色调： 商务深蓝 (#23649F) —— 用于标题、导航栏、主要图表，体现专业与稳重。




 	- 
辅助色： 活力翠绿 (#009546) —— 仅用于关键数据高亮、增长趋势箭头或图标点缀，避免大面积使用。






 	- 
排版要求：




 	
图文并茂，每页自动匹配高质量、无版权风险的商务场景图片或极简图标。




 	- 
字体选用无衬线字体（如微软雅黑/思源黑体），确保跨设备兼容。







Content Outline (PPT大纲):
[在此处粘贴您在第二步获得的 Markdown 内容]






### 💡 核心优化点说明


 	- 
角色锚定（Role Anchoring）： 在第一步和第四步都加入了具体的“角色”定义（如“国企管理顾问”），这能让 AI 自动调整语气的严肃程度和用词的精准度。




 	- 
格式强约束（Format Constraint）： 在第二步特别强调了 Markdown 的输出格式。这不仅仅是为了好看，而是为了标准化。标准的 Markdown 结构能被绝大多数支持“文档转 PPT”的 AI 工具（包括豆包、WPS AI、Gamma 等）精准识别，避免生成时出现乱码或层级混乱。




 	- 
视觉颗粒度（Visual Granularity）： 在第四步将颜色具体到了 Hex 色值（#23649F）。AI 对“深蓝”的理解千差万别，提供色值能确保生成的 PPT 不需要您再手动去调色盘里找颜色，直接达到企业级 VI（视觉识别）标准。
