### 一、PTrade 是什么？为什么值得新手选？

PTrade 是恒生电子为券商定制的专业量化交易终端，也是目前个人投资者门槛较低、较易上手的量化平台之一。它把策略编写、历史回测、模拟交易、实盘交易四大环节，集成在一个环境里——不用自己搭建复杂的本地环境，安装登录后就能从零开始。

它用 Python 写策略，原生支持 Pandas、Numpy 等常用分析库，有基础的上手快；就算完全没编程经验，也有内置的零代码工具。更重要的是：**策略部署在券商云端，关掉本地电脑也不中断交易**，适合要长期稳定跑策略的人。

### 二、怎么开通和安装？

**开通条件**：PTrade 不是独立软件，要通过合作券商申请。不同券商资金门槛不同，有的 10 万就能免费开通，有的要 30-50 万。开通前要做风险测评，等级一般要达到 C3（积极型）及以上。

**开通流程**：

- 选一家支持 PTrade 的券商（比如你开户的那家，联系客户经理确认）；

- 完成开户和资金验资；

- 在券商 APP 或官网提交开通申请、签风险协议；

- 等审核，一般 1-3 个工作日。

**安装步骤**：审核通过后券商发下载链接 → 解压到非系统盘、用全英文路径（避免中文路径兼容问题）→ 运行安装 → 用资金账号登录、完成风险测评。

### 三、PTrade 五大核心界面

**① 行情模块**：看盘入口，支持沪深 A股、指数、ETF、债券、期权等行情。能看分时图、多周期 K 线，内置 MACD、KDJ、BOLL 等几十种指标。

**② 交易模块**：手动+量化交易都在这，支持限价/市价委托、自动拆单，实时看持仓盈亏。

**③ 工具模块**：零代码量化工具箱，内置 17+ 工具（追涨停、网格交易、ETF 套利、可转债转股等），不用写代码就能自动交易。

**④ 量化模块**：核心，分研究、回测、交易、帮助四块。研究环境类似 Jupyter，回测验证策略，实盘部署到云端。

**⑤ 日内模块**：日内回转交易用，适合可转债、ETF 日内套利这类 T+0 场景。

### 四、Python 策略编写入门

PTrade 是事件驱动的框架，一个完整策略通常有这几个函数：

- **initialize**：策略启动时运行一次，用来设股票池、参数、风控；

- **before_trading_start**：盘前运行，更新数据、算信号；

- **handle_data**：盘中核心，交易逻辑主要写这；

- **after_trading_end**：盘后运行，记录数据、生成报表。

举个最简单的均线金叉死叉例子（股票代码仅为示例）：

def handle_data(context, data):
    position = get_position(g.stock)
    hist = get_history(10, '1d', 'close', g.stock)
    ma5 = hist[-5:].mean()
    ma10 = hist[-10:].mean()
    # 金叉买入：5日线上穿10日线
    if ma5 > ma10 and position.amount == 0:
        order_value(g.stock, context.portfolio.cash)
    # 死叉卖出
    if ma5  0:
        order_target(g.stock, 0)
常用 API：set_universe（设观察池）、get_history（取历史数据）、order_value（按金额买）、order_target（调整到指定数量）、get_position（查持仓）、context.portfolio（看账户资产）。

### 五、策略回测：验证策略靠不靠谱

回测是用历史数据模拟跑策略，验证它赚不赚、风险大不大。流程：新建策略 → 写/导入代码 → 设回测参数 → 运行。

**回测参数设置要点**：

- 回测时间：建议至少 1 年以上，覆盖不同市场环境；

- 初始资金：设模拟的初始资金；

- 佣金费率：通常设万 3 左右；

- 滑点：通常 0.1%-0.3%（成交价和预期价的差）；

- 业绩基准：选沪深 300 等指数对比。

**重点看这些指标**：年化收益率、**最大回撤**（最惨亏多少，重要！）、胜率、夏普比率（风险调整后收益）、收益曲线、持仓明细。别只看收益率，**回撤太大说明策略太冒险**。

### 六、实盘上线与风控

回测稳定后，别急着上真钱。先模拟盘跑 1-2 周验证实时行情下的稳定性，再实盘部署。

**实盘风控重中之重**，策略里要加：

- 单笔最大金额限制，避免单次亏太大；

- 单日最大亏损限制（比如亏 3% 就停）；

- 持仓集中度限制（单只不超总资金 20%）；

- 涨跌停过滤、流动性过滤（避免买不进卖不出）。

**实盘注意**：尽量用限价单别用市价单（市价单成交价可能严重偏离预期）；检查有没有未完成订单避免重复下单；初期小资金测试，逐步放大；定期复盘调整参数。

### 七、常见问题

**登录问题**：提示"同步连接超时"多是客户端版本旧，重装最新版；无法登录可能是券商系统维护（多在周五到周六）或交割时间（20:00-22:00），等会儿再试。

**回测问题**：实盘客户端可能没回测按钮（部分券商实盘客户端取消了），要用模拟客户端回测；回测和实盘表现不一致，可能是回测用瞬时成交而实盘靠柜台同步，要加订单监控。

**策略运行**：策略部署在云端，关客户端不影响；但零代码工具要客户端开着。报错看日志面板，常见是代码格式错、API 调用错、第三方库版本不兼容。

### 八、总结：给你的上手建议

PTrade 降低了量化门槛，让普通投资者也能用专业策略交易。但量化是不断学习优化的过程，建议：

- **从简单策略开始**，逐步积累再尝试复杂的；

- **始终牢记风控**，不要过度依赖策略；

- **定期复盘调整**，市场会变，策略也要跟着优化。

### 常见问题 FAQ

#### 问：完全不会编程，能用 PTrade 做量化吗？

答：可以。PTrade 内置零代码工具（如网格交易、追涨停等 17+ 工具），不用写代码也能自动化交易。如果想自定义策略，建议学一点基础 Python。

#### 问：PTrade 和 QMT 有什么区别？

答：两者都是券商量化终端。QMT 更偏数据和自建系统，灵活度高；PTrade 策略部署在券商云端、开箱即用，回测和实盘集成好，对个人更友好。按你的需求和技术基础选。

#### 问：PTrade 策略会不会因为电脑关机就停？

答：不会。策略部署在券商云端服务器，关掉本地电脑不影响策略运行。但零代码工具需要保持客户端开启。

#### 问：用 PTrade 实盘交易有风险吗？

答：任何实盘交易都有风险。务必先在模拟盘验证、用限价单、加好风控（单笔限额/单日止损/集中度限制），初期小资金测试。工具只是执行，判断和风控要自己把关。
