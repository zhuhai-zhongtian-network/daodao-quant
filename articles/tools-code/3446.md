### 一、先搞懂 OpenRouter 是什么

简单说，它是个"大模型聚合中转站"：把 GPT、Claude、Llama 这些全球顶级模型的 API 聚合到一个地方，你用一套接口就能调用它们。

对做工具、做插件的人来说，好处很明显：

- **一个 Key 调所有模型**：不用逐个对接 OpenAI、Anthropic 的官方接口；

- **价格更低**：通常比官方低 10%-30%，调用多能省不少；

- **模型随便切换**：想换模型，改个模型名称就行，不用改代码。

### 二、第一步：注册账号，拿到 API Key（5 分钟）

**第 1 步**：打开 OpenRouter 官网，点右上角 "Sign Up"，用邮箱或谷歌账号注册。

**第 2 步**：登录后，点顶部菜单 "API Keys"，再点 "Create Key"。给 Key 起个名字（比如你网站的名字），点创建。

**第 3 步**：立刻复制生成的 API Key（**只显示一次**，丢了只能重新建），存到安全的地方（密码管理器或本地备忘录）。

**第 4 步**：点顶部 "Billing"（账单），绑定信用卡或支付宝。最低充值 10 美元，按实际调用量扣费，不用预存太多。

### 三、核心：调用接口的标准格式（含流式输出）

OpenRouter **完全兼容 OpenAI 的 API 格式**，所以所有支持 OpenAI 接口的工具和插件，都能直接切换过去，非常省事。

**接口地址**：

https://openrouter.ai/api/v1/chat/completions
**必带请求头**：

Authorization: Bearer 你的API Key
Content-Type: application/json
**请求体示例**（开启流式输出，实现逐字打字效果）：

{
  "model": "anthropic/claude-3.5-sonnet",
  "messages": [
    {"role": "user", "content": "帮我解释一下量化交易里的风险控制"}
  ],
  "stream": true,
  "max_tokens": 2000
}
这里 stream: true 是关键——开启后，回答会像打字一样逐字出来，用户不会觉得"卡死了"。

### 四、重点：集成到你的 WordPress AI 插件

如果你的 WordPress AI 插件支持"自定义 OpenAI 接口"，按下面几步就能用上最新模型 + 流式输出：

**第 1 步**：登录 WordPress 后台，找到 AI 插件的"设置 → API 配置"。

**第 2 步**：把默认的 OpenAI 接口地址，替换成上面的 OpenRouter 接口地址。

**第 3 步**：把插件里的 API Key，换成你在 OpenRouter 生成的 Key。

**第 4 步**：找到"响应模式"，勾选"流式输出"或"实时打字效果"（有开关就开；如果插件没有这个开关，因为传了 stream=true，大部分兼容插件会自动触发流式）。

**第 5 步**：在"模型名称"输入框，填 OpenRouter 支持的模型标识（比如 anthropic/claude-3.5-sonnet）。

**第 6 步**：保存设置，到前台提一个复杂问题，就能看到文字逐字跳出来。

### 五、本地测试：用 Python 先验证流式效果

怕直接改插件出问题？先在本地跑通。用下面这段 Python 代码，替换成你的 API Key 就能测（我用的是安全的 json 解析，比网上流传的 eval 写法更可靠）：

import requests, json

url = "https://openrouter.ai/api/v1/chat/completions"
headers = {
    "Authorization": "Bearer 你的OpenRouter API Key",
    "Content-Type": "application/json"
}
data = {
    "model": "anthropic/claude-3.5-sonnet",
    "messages": [{"role": "user", "content": "详细解释量化交易中的阿尔法因子"}],
    "stream": True
}

response = requests.post(url, headers=headers, json=data, stream=True)
# 逐字打印效果
for line in response.iter_lines(decode_unicode=True):
    if line and line.startswith("data: ") and line != "data: [DONE]":
        try:
            json_data = json.loads(line[6:])
            content = json_data["choices"][0]["delta"].get("content", "")
            if content:
                print(content, end="", flush=True)
        except Exception:
            pass
运行后，文字会一个字一个字蹦出来——这就是流式输出。跑通后再去改插件，心里有底。

### 六、避坑指南（针对做量化工具的特别提醒）

**① 模型选择**：做量化策略分析，优先选逻辑推理和长文本强的模型（如 Claude 系），能处理代码和复杂逻辑；如果做低成本日常问答，可以选性价比高的开源模型（如 Llama 系），价格只有前者的几分之一。

**② 预算控制**：在 OpenRouter 控制台 Billing 里设置"月度消费上限"，避免用户大量提问导致超支。

**③ 插件不流式怎么办**：如果改了接口还是不流式，多半是前端渲染逻辑没接收流式数据。可以检查插件版本，或联系插件作者，说明"已切到 OpenRouter 接口、传了 stream=true，请检查前端是否接收流式数据"。

**④ 错误排查**：调用失败先看控制台 "Logs" 里的错误日志。大部分是 API Key 填错，或模型名称写错（比如少了 "anthropic/" 这类前缀）。

### 七、为什么比直接用官方接口更适合

- **省钱**：同一模型，OpenRouter 通常比官方便宜 10%-30%。问答调用多的话，长期能省下可观费用；

- **省心**：一个 Key 调所有模型，不用对接多个官方接口，后续想升级模型，改个名称就行；

- **流式友好**：原生支持 stream 参数，刚好解决"用户不知道 AI 在工作"的体验痛点。

### 常见问题 FAQ

#### 问：OpenRouter 一定要充值才能用吗？

答：注册后一般会有少量免费额度可试用，但正式调用需要充值（最低 10 美元），按实际用量扣费。建议先充小额测试跑通，再按需充值。

#### 问：我的 WordPress 插件不支持自定义接口怎么办？

答：先确认插件是否支持 OpenAI 兼容接口。如果不支持，需要换支持自定义接口的插件，或请开发者加一个接口地址配置项。

#### 问：流式输出一定要在代码里设置吗？

答：是的，请求体里要传 stream: true。如果插件没有流式开关，但传了这个参数，多数兼容插件会自动触发逐字输出。

#### 问：调用 OpenRouter 有没有封号或风险？

答：OpenRouter 是正规的 API 中转平台，正常付费调用合规。注意不要滥用、不要把它接在违法违规场景，遵守平台服务条款即可。
