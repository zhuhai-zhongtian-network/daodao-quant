## MiniQMT量化接口调整，一个做审计的人，看到的却是另一件事




近期有券商对MiniQMT权限的新增与存量安排作了调整。消息一出，个人量化圈讨论热烈。这几天，饭局上、微信里，好些做量化的朋友都在念叨这件事，有人还半开玩笑地问我：'老道，我这套跑了几年的策略，是不是要跟着'下岗'了？'我笑了笑，也认真想了想。只是一个本地Python接口的调整，为什么影响这么大？是行业在规范，还是这条路以后不好走了？





作为一个做了三十多年财务审计和内控、如今自己用AI做量化的人，我看这件事的视角可能和大多数人不太一样。圈里都在聊"工具没了怎么办"，我更想聊聊：**这背后到底是什么在变，以及一个普通人该怎么自处。**





### 一、为什么MiniQMT会有调整？从一个审计师的直觉说起




先给不熟悉的朋友讲清楚：MiniQMT把xtquant库开放给本地任意Python环境，你可以用VSCode、PyCharm自由写代码，策略跑在自己电脑上，只调用券商的行情与交易接口。这种自由度，是过去几年个人量化爆发的基础。





但作为一个常年做内控的人，我第一眼看到这个架构，本能就会去想：这套架构的管控责任，究竟如何落实。





监管的核心要求是穿透式管控——券商作为第一责任主体，要看得见策略行为、能拦截异常报单、能回溯交易逻辑。可MiniQMT模式下，策略跑在投资者本地主机，券商只能看到最终报单，看不到策略代码、触发逻辑、信号来源。用户本地还能随意对接外部脚本、网络服务，券商很难做前置风控。





用审计的语言说，这就是一个**一个值得关注的内部控制议题**：交易指令的生成和风控，游离在券商的可控范围之外。一旦出现恶意报撤单、多账户联动、异常交易，交易所追责的是券商。对券商来说，这需要在风控责任上更审慎地权衡。





绝大多数MiniQMT用户，只是写网格、波段、转债轮动、指数定投，用程序代替盯盘，很朴素。但监管不区分你的初衷，只看系统架构是否满足管控要求。**这种架构的调整，是行业发展的整体趋势，并非某一家券商的选择。**





### 二、划重点：不是禁量化，是"本地直连接口"这条路在调整




很多人恐慌，其实有个误解要先澄清：






- **不是QMT整个调整**——标准版QMT完整保留，能力不弱，tick回测、篮子交易、条件单、Python策略全都支持，底层交易通道和MiniQMT同源。

- **不是禁止个人做量化**——QMT、PTrade等官方终端仍向个人开放，个人用自有账户做策略交易完全合法，只是运行环境被框定在券商管控终端内。

- **被调整的，是"本地独立进程直连交易接口"这种接入方式。**





换句话说，牺牲的是开发者的自由开发环境，不是交易能力本身。这个认知很重要——它决定了你是恐慌，还是冷静迁移。





### 三、审计老兵给普通量化者的一句话忠告




这些年做内控，我最深的体会是：**规则从来不是针对某个人，而是着眼于整个系统的平稳运行。**监管的核心目标是管控异常交易、恶意报撤单、高频报撤单、多账户联动这些扰乱市场的行为。但技术上不易区分各类策略的用途，于是从系统接入架构上做统一的规范管理。这是制度成本，也是所有个人量化者要共同承担的现实。





所以我的建议很朴素，分三步：






- **别赌"不会关"。**存量还能用，但新策略不要再基于MiniQMT开发。提前梳理核心策略，分批往标准版QMT迁移。

- **走两条合规路线。**路线A：标准版QMT，适合熟悉xtquant、中低频为主的交易者；路线B：PTrade，适合想托管运行、习惯云原生的交易者。别把精力耗在各种变通桥接方式，短期应急可以，不是长期实盘底座。

- **回归量化本源。**工具环境变化，会提高工程成本，但不会消灭有效的交易逻辑。策略逻辑、回测体系、风控体系这些核心资产，不会因为工具变化而失效。





### 四、这件事，恰恰印证了我一直以来的选择




很多人问我，为什么我做量化，反复强调风控、强调合规、强调"不荐股不承诺收益"。MiniQMT这件事，就是一个活生生的注脚：**在金融市场，规则和风险永远走在工具前面。**





做审计这行养成的习惯，让我天生对'稳定'和'经得起检验'这两件事格外较真。就像家里那台用了十几年的老空调，坏了修、修了再用，一直舍不得换——能用、好用、不折腾，比什么都强。我做量化也是这样，从来不是追求技术上的极致自由，而是追求稳定、可持续、经得起检验。这也是为什么我坚持用数据、用逻辑、用纪律，而不是赌一个接口、赌一个工具。工具只是舟，真正要去的彼岸，是长期稳定可复制的投资结果——而这个结果，靠的是对市场的理解、对风险的敬畏，不是某个IDE好不好用。





以上是我的一些看法，供参考，也欢迎交流探讨。行业在变，但有些东西不会变。





### 常见问题（FAQ）




#### 问：MiniQMT调整，是不是散户不能做量化了？




不是。QMT、PTrade等官方量化终端仍向个人开放，个人用自有账户做策略交易合法，只是运行环境被框定在券商管控终端内。被调整的是"本地独立进程直连交易接口"这种接入方式。





#### 问：MiniQMT用户现在该怎么办？




存量还能用，但别赌"不会关"。提前梳理核心策略，分批向标准版QMT或PTrade迁移，别把实盘长期依赖在正在调整的接入方式上。





#### 问：为什么监管要管这个？




核心是管控异常交易、恶意报撤单、高频报撤单、多账户联动等扰乱市场的行为。技术上不易区分各类策略的用途，于是从系统接入架构做统一的规范管理。
