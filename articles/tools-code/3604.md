### 5.2 Redis：数据同步层（难度★★）

**作用：** 中间缓存，让QMT(Windows)与AI分析(Linux)跨机通信。

**Key设计规范（骨架）：**
qmt:real:account:asset        → 账户资产
qmt:real:account:positions    → 持仓明细
qmt:real:archive:trades:日期   → 当日成交
qmt:real:daily:OHLCV:代码      → 日线行情
qmt:real:watchlist            → 监控池

> 💡 **付费节点建议：** 完整Key规范与同步脚本可设为付费。

## 十二、关键设计原则与避坑

### 科学原则


 	- **分层解耦**：各层独立，单点故障不影响全局

 	- **闭环反馈**：执行结果回写，形成"信号→执行→绩效→优化"

 	- **数据新鲜度校验**：防用脏数据做决策

 	- **同账号一致性**：保证数据真实
