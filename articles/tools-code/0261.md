### 1. 每日作战循环 (The Daily Loop)

目标：保持市场感知，零情绪干扰，确保交易指令准确传达。[erphpdown]






**模块**
**时间锚点**
**标准化动作 (SOP)**
**关键产出**




早盘战备
09:00 - 09:15

1. 扫雷：仅查阅官媒（央行/证监会）及隔夜外盘核心数据。


2. 核单：强制检查所有智能条件单（止损/网格）状态是否为“监控中”。


3. 预演：确认当日关键点位（如：若跌破X元，是否执行B计划？）。



《当日观察清单》


盘中风控
09:30 - 15:00

原则：静默监控，非必要不干预。


1. 警报响应：仅在收到股价预警（触及关键位）时查看行情。


2. 纪律执行：一旦触发止损/买入逻辑，无脑执行，拒绝盘中即兴发挥。



交易执行记录


复盘归档
16:00 - 16:30

1. 数据录入：更新净值表，记录持仓股收盘价。


2. 异动分析：对涨跌幅 &gt;3% 的持仓进行归因（是大盘、板块还是个股原因？）。


3. 参数微调：根据收盘情况，修正次日的条件单触发价（如移动止损）。

### 2. 每周主题特训 (The Weekly Rhythm)

目标：避免信息过载，将复杂的分析工作拆解到每一天。




 	- 
周一：宏观校准 (Strategy)




 	
动作：对比账户净值与沪深300走势。




 	- 
思考：市场风格是在“大盘/小盘”、“成长/价值”哪一端？我的持仓是否逆风？






 	- 
周二/周三：深度研报 (Intelligence)




 	
动作：每周只精读一份核心持仓或目标股的深度研报（侧重风险提示章节）。




 	- 
目的：验证持仓逻辑是否松动（如：护城河是否受损？）。






 	- 
周四：技术风控 (Risk Control)




 	
动作：全面审计条件单。




 	- 
检查项：止损价是否需要上移（保护利润）？网格区间是否穿破？支撑位是否有效？






 	- 
周五：下周决策 (Planning)
